# 演示截图

将各页面截图放入此文件夹，文件名建议格式：`菜单名-子功能.png`

## 截图清单

| 文件名 | 说明 |
|--------|------|
| `dashboard.png` | 仪表盘总览 |
| `monitor-list.png` | 监控项管理列表 |
| `monitor-http.png` | HTTP 监控项配置弹窗 |
| `monitor-other.png` | 非 HTTP 监控项配置弹窗 |
| `group-list.png` | 监控任务列表 |
| `group-detail.png` | 监控任务详情/关联监控项 |
| `log-list.png` | 执行日志列表 |
| `log-detail.png` | 执行日志详情（含变量/告警） |
| `alert-template.png` | 告警模板管理 |
| `alert-channel.png` | 告警渠道配置 |
| `alert-log.png` | 告警记录列表 |
| `alert-silence.png` | 告警静默规则 |
| `reminder-list.png` | 周期提醒列表 |
| `domain-cert.png` | 域名证书管理 |
| `api-schema.png` | API Schema 管理 |
| `variable-global.png` | 全局变量管理 |
| `variable-group.png` | 任务变量管理 |
| `user-list.png` | 用户管理 |
| `security-settings.png` | 安全设置 |
| `status-page.png` | 公开状态页 |
| `manual.png` | 使用手册 |
| `login.png` | 登录页面 |
| `theme-light.png` | 浅色主题 |
| `theme-dark.png` | 深色主题 |

## 截图建议

- 分辨率：1920×1080 或 1440×900
- 浏览器全屏，隐藏书签栏
- 数据尽量丰富，体现功能完整性
